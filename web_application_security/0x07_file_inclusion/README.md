# 0x07. File Inclusion

This project covers Local File Inclusion (LFI) and Remote File Inclusion (RFI) vulnerabilities in web applications.

## Learning Objectives

- Understand what file inclusion vulnerabilities are
- Identify vulnerable endpoints and parameters
- Exploit Local File Inclusion to read sensitive files
- Understand how improper input validation can expose server files
- Learn basic mitigation techniques such as whitelisting and sanitizing file paths
